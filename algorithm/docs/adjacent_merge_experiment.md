# Connected split and adjacent merge experiment

User direction: stop the combined134/control experiment; test the separate method on data_official_official. Also compare K=1,3,5,7 using silhouette and one shared DINO extraction per image.

`partition_mode=adjacent_merge` retains DINO/SLIC/K-means, splits each label into four-connected components, builds shared-edge adjacency, and merges small pieces across appearance labels. A deterministic score combines PCA-feature distance, shared boundary, occupancy and bounding-box size. Merged bounding boxes cannot exceed 65% of the parent rectangle; minimum occupancy is 25%. Components retain their original membership IDs. Every active pixel is retained. If the region count exceeds the branching target or geometry is poor, use the existing four-way spatial fallback. A target count is not guaranteed when these constraints conflict.

`algorithm.tools.partition_sweep` compares current grouping and adjacent merging for K=1,3,5,7 on every unique image in the requested export. It extracts DINO once per full image, saves a lossless float32 cache at a maximum spatial side of 1024, and shares this cache across all eight configurations. SLIC is selected once per image using the existing entropy procedure. Silhouette uses the same deterministic sample of 512 pixels for every configuration, in the three PCA-color channels plus weighted x/y space. This is not full-dimensional DINO-embedding silhouette. Report raw and post-fallback results separately. K=1 is explicitly unsplit and has undefined silhouette. The sweep is question/answer independent and does not measure task accuracy.

A GPU smoke test on image 000 completed all eight configurations with one encoder call. Full answer/localization evaluation is still required; a larger silhouette is not proof of better answers. Existing defaults remain unchanged. The earlier combined134 run is interrupted and must not be reported as completed or mixed with this experiment.
